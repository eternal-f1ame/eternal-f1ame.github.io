A tongue-in-cheek tracking database that catalogues academic papers published without their accompanying source code — categorized by why the code never showed up ("Ghosted", "Coming Soon™", and friends). Sources data from arXiv, Papers With Code, and GitHub, with stats, leaderboards of the most-cited offenders, and a "Resurrection Corner" for the rare papers that eventually do release their implementations.
