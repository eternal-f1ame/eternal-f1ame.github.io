An image annotation suite that lives inside VS Code — bounding boxes, polygon masks, keypoints, and multi-label classification in one workflow. Real-time canvas rendering with visual feedback, plus standardized export schemas, confidence thresholding, and coordinate normalization, so annotations stay consistent across computer vision tasks.
